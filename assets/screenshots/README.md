# Screenshots

Generated by [`../screenshot.sh`](../screenshot.sh), which runs `boop` in a
fixed-size tmux pane, captures the pane's rendered screen with its ANSI intact,
converts it with [`../ansi2png.py`](../ansi2png.py) and rasterises it through
headless Chromium.

These are real terminal captures, not mock-ups.

```bash
./assets/screenshot.sh tui-main "boop — main view"
COLS=120 ROWS=40 ./assets/screenshot.sh tui-wide "boop — wide terminal"
./assets/screenshot.sh tui-approval "boop — approval prompt" /tmp/keys.txt
./assets/screenshot.sh tui-config-editor "boop — /config editor" /tmp/config-editor-keys.txt
```

A keystroke script drives the UI before capture, one instruction per line:

```
wait:1
send:/help
key:Enter
wait:2
```

Requires `tmux`, `python3`, ImageMagick and Chromium.
