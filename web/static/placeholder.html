boop — WebUI

The server is running, but no frontend bundle is embedded in this binary.

Build the bundle and rebuild the binary:

make web-build
make build

The API is live regardless of the frontend. Useful endpoints:

  • GET /api/status — runtime health and build metadata
  • GET /api/config — configuration with secrets redacted
  • GET /api/events — WebSocket event stream
Boop is a local-first tool. Do not expose this interface to the public Internet without a reverse proxy that terminates TLS and authenticates callers.
